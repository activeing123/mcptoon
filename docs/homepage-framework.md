# 营销面框架（Marketing Surface Framework）

> 状态：**待人工闸①批复**。2026-09-16 grill 两轮定根；术语见 `CONTEXT.md`（Marketing Surface / Single-page Hub / Homepage Reader / Human Checkpoint）。
> 本文档是营销面（落地页 EN+ZH + README 英中）的**章法**：刀法（怎么写怎么排）一律服从这里。

## 1. 使命（一句话）

**让冷路过的陌生人，在 5 秒内想要跑第一条命令。**
一切区块取舍、文案优先级，都拿这句话当尺子。留存力不足 = 使命未达，与"有没有被攻击面"无关。

## 2. 第一画像（grill R2-Q6 定：B 主 A 辅 C 垫）

| 顺位 | 人 | 进门状态 | 他需要什么 | 页面义务 |
|---|---|---|---|---|
| 主 | **冷路过的** | 从社媒/榜单/口口相传点进来，**还没意识到自己在交 MCP token 账** | 扎心一下 + 眼见为实 | 首屏钩子、现场输出、计算器 |
| 辅 | 已痛搜进来的 | 带着"怎么省"的问题来 | 共鸣 + 快速上手路径 | 四步区块、命令行 |
| 垫底 | 选型评估者 | 替团队/未来的自己查底细 | 背书、参数、风险兜底 | spec/FAQ——**只兜底，不占首屏** |

病理复盘：旧版把信任分刷到 97/100，是因为整页按 C 的疑心写、按红蓝的攻防写；**B 没被服务过**。

## 3. 四文件分工（漏斗段交接，grill R2-Q7 定）

| 段 | 谁负责 | 干什么 |
|---|---|---|
| 点火（没想过→想要） | 落地页 hero | 身份钩子 + 折钱 + 现场终端 + 计算器 CTA |
| 信任（想要→敢信） | 落地页 proof + clients | 第三方数字、接线图，第二屏内必须出现 |
| 转化（敢信→跑第一条命令） | **README** | 一行安装 + quickstart + stats 自证闭环 |
| 兜底（细节/逃生舱/参数） | 落地页后半 + docs/ | spec、FAQ 保留，降为兜底层 |

- README 义务：前 10 行内出现一次落地页链接（明确交接线）；自证三步（装→quickstart→stats）为第一动作。
- 落地页义务：不再向已装好的人重复 README 的安装细节，指过去即可。

## 4. 信息架构：单页枢纽制（grill R1-Q4 定）

落地页 = **唯一枢纽叙事**；token-tax 计算器 = **唯一卫星页**；docs/ **不建站**。
ADR 判定：不另立 ADR——此决定可推翻且成本低（三条里"难以逆转"不成立），本文档即上下文。

## 5. 落地页区块职责清单（EN 母版；ZH 由 merge_zh.py 再生）

| # | 区块 | 一句话职责 | 服务画像 | 成功判据 |
|---|---|---|---|---|
| S1 | hero | 扎心+折钱+活终端+计算器，5 秒成交"想跑命令" | B | 三秒测试：说得出一句话、指得出下一步 |
| S2 | proof | 接住"这数真的假的"——第三方亲发数字 | B 怀疑瞬间 | 第二屏内进入视口 |
| S3 | how 四步 | 量→砍路径，A 的共鸣+上手 | A | 每步一行内 |
| S4 | before-after | 同一环境两张账单 | A | 数字全带尺子 |
| S5 | math | 三档梯子+数的来路（尺子对照表） | A/C | 只服务往下滚的人，不拦路 |
| S6 | clients | 接线图=活着的产品 | B/C | 无 logo 墙滥情 |
| S7 | spec | 参数表，小字放大写 | C | 数字全带日期 |
| S8 | FAQ | 异议处理+逃生舱 | C | 只答真被问过/会被问的 |
| S9 | footer | 两条命令行 + colophon（谁做的、怎么验证） | A/C | — |

**排序铁律：B 在前半（S1-S2），A 中段（S3-S5），C 后半（S6-S9）。** 砍区块=先证明它同时服务不了 B，不许为"周全"保留。

## 6. 铁律继承（不可逆条款，红蓝八轮换的）

1. **数字带尺子**：每个页面数字有台账出处；口径黑名单继续生效（附录 C）。
2. **EN 母版制**：改 EN + merge_zh.py 锚点，ZH 永不手改；鬼魂表防回潮。
3. **闸链**：merge_zh → pair_audit → 390 溢出 → WCAG → 渲染 → 校验官（裁判分离）。
4. **未经用户批复不 push / 不部署**（红线不变）。

## 7. 人工闸（Human Checkpoint，grill R2-Q8 定）

1. **①框架终审**＝本批复（现在）。
2. **②重排令**：拿 §5 清单裁决旧页面前，改动清单先给你看。
3. **③三秒实测**：新版落地页+README 并排开浏览器，你 3 秒看首屏 → 复述"这产品干嘛 + 下一步点哪"，说不出即回炉。
4. **④出门闸**：部署/合仓/og 图/push 四件套（存量挂起项，见 §9）。
5. **改向纪律**：中途任何换钩子、删区块、动数字口径——先问后动。
