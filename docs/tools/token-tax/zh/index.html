这些数字是什么意思。原始 = 客户端为每个工具上传的 JSON Schema。 名字索引 = 只有工具名，而名字正是你判断「该调哪个」所需要的全部信息； 完整 schema 改成按需取一个工具的那一份，而不是所有工具的一整套。

本页的估算从一个实测锚点线性外推，所以你自己那套会不同。 名字索引这一行是这里最软的数：在我们三套配置上实测是 每工具 2.3–4.1 token，取决于你的工具名有多长，本页用的是 255 工具锚点的 2.28 token/工具。对两套更小的配置，这会让省下的比例虚高约 1%。 更小的原始清单每工具也会比均值略贵，因为每台服务器都带自己的表头。 锚点数字是逐字节实测的 —— 就是本仓库 assets/benchmark_tiktoken.json 的 255 工具那一行；本页是 30 秒估算版。 要真数：克隆本仓库后运行 python scripts/bench_tokens.py （它是仓库脚本，不在 wheel 里）。
