What does your MCP tool list cost you?

Every MCP client ships the model the full JSON schema of every tool before you ask a single question. This calculator estimates that bill for your own setup. 🔒 runs entirely in your browser — nothing is sent anywhere

What the numbers mean. Raw = the JSON Schema every client uploads for every tool. Name index = the tool names only, which is what you actually need to decide which tool to call; full schemas are fetched on demand for one tool instead of pushed for all of them.

Estimates scale linearly from one measured anchor, so your mix will differ. The name-index row is the softest number here: measured across our three setups it costs 2.3–4.1 tokens per tool depending on how long your tool names are, and this page uses the 2.28 tokens/tool of the 255-tool anchor. On the two smaller setups that flatters the savings by about 1%. Small raw listings also cost a little more per tool than the mean, because each server carries its own header. The anchor numbers are measured byte by byte — they are the 255-tool row of assets/benchmark_tiktoken.json in this repository; this page is the 30-second estimate. Measure your own for real: run python scripts/bench_tokens.py from a clone of this repository (it is a repo script, not part of the wheel).
